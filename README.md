# IGNITE Leadership Club

> **Preparing Students for Life, Leadership, and Purpose.**
> A school-based youth development system designed to cultivate leadership, civic responsibility, and career readiness.

## Overview

IGNITE is not a one-time seminar — it is a structured, sustainable youth development system embedded within secondary schools. The platform serves as the official portal for schools, students, government stakeholders, and CSR partners.

## Features

- **Hero & Mission Section**: Clear value proposition and mission statement.
- **Strategic Pillars**: Dedicated modules for Leadership, Digital Literacy, Career Pathway Guidance, and Community Impact.
- **Pilot & Milestones**: Tracking metrics and real-world outcomes.
- **School & Partner Onboarding**: Pathways for educational institutions and sponsors to participate.
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.

## Deployment on Vercel

This repository is structured as a zero-configuration static site ready for immediate hosting on [Vercel](https://vercel.com):

1. Import the repository in your Vercel dashboard.
2. Select default settings (Framework Preset: **Other** / Root Directory: `./`).
3. Click **Deploy**.
